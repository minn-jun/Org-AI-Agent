| 7. 장애물 감지 인식률 | % | 90% | • 위험 감지 센서를 통해 측정된 입력 값 중 실제 장애물이 있는 상황에서의 값과 장애물이 없는 상황에서 측정된 값의 구분을 통한 장애물 감지 인식률 측정 |

| 9. 영상/음성 데이터 전송 응답 속도 | sec | 3sec 이내 | • 비대면 실내외 활동보조 도움 플랫폼을 실제로 이용하는 시뮬레이션 동작을 통한 서비스 응답속도 측정 • 서비스( Rest) 를 통해 적절한 시간 내에 API 들이 반응하는지 확인 |
