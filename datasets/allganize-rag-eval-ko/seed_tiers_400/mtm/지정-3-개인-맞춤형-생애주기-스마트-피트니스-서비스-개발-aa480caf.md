# (지정-3)개인 맞춤형 생애주기 스마트 피트니스 서비스 개발

| 과제명 |  | 개인 맞춤형 생애주기 스마트 피트니스 서비스 개발 |  |  |
| 1. 개요 및 필요성 |  |  |  |  |
| ○ 개요 피트니스에 대한 전문적인 지식이 없는 사용자도 전문 트레이너에게 개인별 맞춤형 트레이닝을 피트니스 생애주기(측정->진단->처방->예측->사후관리)에 따라 관리 받는 것과 같은 효과를 얻을 수 있는 AI 기반의 피트니스 코칭 서비스 기술 개발 ○ 필요성 : 주 5일제 근무와 주 52시간 근무제도의 도입으로 일반인들의 여가 시간이 증대 되면서 피트니스, 사이클, 조깅, 필라테스 등과 같이 다양한 신체관리를 위한 생활 스포츠에 대한 관심이 증대되어 올바른 피트니스 코칭 서비스가 필요함 생활 스포츠에 대한 관심은 IT 기술과 접목하여 웨어러블 디바이스, 스마트워치, 건강관리앱 등 헬스케어 산업 시장의 확대를 통해 피트니스 수요가 증가하고 있어 개인 맞춤형 피트니스 서비스가 요구되고 있음 맞춤형 개인 건강관리를 위한 웨어러블 디바이스, 스마트워치, 건강관리앱 등은 사용자의 소모 칼로리, 걸음 수, 심박 정보와 같은 신체 종합 정보와 측정 정보 기반의 올바른 피트니스 가이드 서비스 제공이 필요함 스마트 피트니스를 통한 개인 건강관리에 취약한 저소득층에 대한 주기적 관리가 가능하여 국민 보건복지 향상이 요구됨 국민 개개인의 건강관리뿐만 아니라 국민 전체에 대한 건강관리 현황 파악을 지원하는 인공지능 기반 스마트 피트니스 서비스가 필요함 올 바른 개인 건강관리와 피트니스 코칭 정보를 제공하고, 그에 따라 맞춤형 피트니스 관리를 제공할 수 있는 스마트 피트니스 서비스 플랫폼이 필요함 공동주택( ex : 아파트), 학교 등의 공공/사설 피트니스 센터에 주민들의 편의를 도모하기 위해 자동화된 피트니스 트레이너와 관리자 지원이 요구되고 있음 |  |  |  |  |
| 2. 연구목표 |  |  |  |  |
| ○ 최종목표 생애주기 개인 맞춤형 피트니스 관리를 위한 지능형 트레이너기반 피트니스 코칭 서비스 개발 ○ 연구내용 한국형 BMI 모델 생성 및 분석 기술 개발 정형/비정형 피트니스
