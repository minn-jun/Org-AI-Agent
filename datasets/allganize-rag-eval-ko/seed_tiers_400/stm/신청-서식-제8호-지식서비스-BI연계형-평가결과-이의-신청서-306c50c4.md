# [신청 서식 제8호-지식서비스(BI연계형)] 평가결과 이의 신청서

[ 신청 서식 제 8호 ]
평가결과 이의 신청서
사 업 명 과제번호 과 제 명 주관기관 총괄책임자 참여기 관(책임자) 평가결과 이의사유 ※ 이의 신청은 평가결과에 대해 평가 방법 및 절차에 중대한 하자가 있 을 경우에만 신청 가능함 이전 평가위원회 기피 여부 이전 평가위원 전체에 대해 기피 신청 함( )/하지 않음( )

|---|---|
| 과제번호 |  |
| 과 제 명 |  |
| 주관기관 |  |
| 총괄책임자 |  |
| 참여기 관(책임자) |  |
| 평가결과 |  |
| 이의사유 | ※ 이의 신청은 평가결과에 대해 평가 방법 및 절차에 중대한 하자가 있 을 경우에만 신청 가능함 |
| 이전 평가위원회 기피 여부 | 이전 평가위원 전체에 대해 기피 신청 함( )/하지 않음( ) |
※ “ 이의사유 ” 란에 평가 방법 및 절차상의 문제점을 기재한 후 공문으로 발송하여야 함
※ 이의 신청 공문 발송 시 “ 이전 평가위원회 기피 여부 ” 란에 반드시 표기하여야 함
