# 20210430 스마트글래스 미팅 자료_v1

2020년도 산업기술혁신사업
시야확보 주변위험 보조 및 잔존시력의 
정보인지 능력 발달을 가능케 하는 
Low Vision Smart Galss 및 서비스 개발
주관기관: ㈜피씨티 정정일
참여기관: 가천대학교 조진수 교수
진행 사항 – 가천대
스마트 글래스 연구 관련 사항 조사 및 연구장비 구매
- 이미지 전송 테스트 결과
- 사용 프로토콜 : RFCOMM 프로토콜
- 방식 : 직렬 포트 SPP (Serial Port Profile)
- Baudrate : 9600
- 1. Android App <-> 라즈베리파이 블루투스 연결
- 2. 라즈베리파이에서 Python 실행 
- 3. Python에서 특정 경로의 이미지 파일 read 후   Binary 데이터로 Android App에 전송
- 테스트 이미지 파일 (2.4MB) - 해상도 2592x1944
- 소요시간 : 22초~24초
- baudrate (bps) 등의 수치 조정 및 파일 read시 속도를 개선할 수 있는 방법 연구 중
[RPI Zero – Bluetooth 통신 테스트]
