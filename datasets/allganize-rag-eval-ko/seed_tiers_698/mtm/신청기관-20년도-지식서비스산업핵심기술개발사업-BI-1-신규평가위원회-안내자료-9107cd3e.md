- ㅇ 20. 6. 24.( 수 ) ~ 6.25.( 목 ) : 수행기관이 업로드 한 답변 및 첨부파일 검토 ( 평가위원 )
- ㅇ 20. 6. 26.( 금 ), 13:00~18:00 : 화상회의 프로그램을 통해평가위원과 화상으로 질의응답 * 실시
- 각 기관별 별도의 발표 없이 20 분 질의응답 실시
- 통신환경이 원활한 장소에서 참석 요망 ( 통신 상태 불량 등에 대해 시간 연장 불가 )
