1. FPGA 기반 점자 핀 인식을 위한 서브 보드 시리얼 통신 모듈 개발
(2)-1. 서브 보드 핀 데이터 요청 및 수신
• 핀 데이터 처리를 위해 메인 보드와 서브 보드간의 버퍼 송수신을 통해 핀 데이터 값을 수신하여 처리함
- 메인 보드에서 요청하는 데이터를 핀 상태 값을 저장하고 있는 HW 서브 보드로 부터 상태 값을 전달받아 핀 정보를 저장함
- serial_Service 클래스 내의 ‘ writeUartData() ’ 함수를 사용하여 핀 데이터를 요청함
- HW 서브 보드에서는 메인 보드로부터 핀 정보 요청 메시지를 수신 후 응답 메시지에 핀 정보를 담아서 전달해 줌으로써, 메인 보드에서 핀데이터를 저장함
HW 키보드 버튼 메시지 정의
| HW 키보드 버튼 메시지 정의 |
|---|
• 서브 보드로부터 수신한 핀 데이터는 ArrayLinst
형태로 line 단위로 핀 상태 값을 저장하도록 구현함
- 핀 상태 값 저장은 Serial_Service 내에 구현한 ‘ SetPinData() ’ 함수에서 동작을 수행함
- HW 서브 보드에서 전달하는 핀 상태 값이 핀이 꽂힌 상태는 ‘9’, 핀이 없는 상태는 ‘1’ 로 전달하므로 이를 개발에 혼돈이 없도록하기 위해 역으로 변환해 주는 ‘ Reverse() ’ 함수를 구현함
