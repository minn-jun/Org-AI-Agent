1. 기기 스펙 및 기능 개요
- OrCam 지원 기능
- TTS 출력 : 도서, 신문, 잡지, 모니터 등의 텍스트를 OCR 기술을 통해 인식하여 TTS 제공
- 음성 인식 : 명령어를 지정하여 명령어를 말하면, 명령어에 따른 기능 수행(음량 조절 등)
- 색상 감지 : 화면에 인식되는 색상을 감지하여 음성으로 읽어주는 서비스 제공
- 모션 인지 : 카메라로 손의 모션을 인지하여 저장된 기능 제공
- 안면 인식 : 최대 100명까지의 얼굴정보를 저장하여 인식기능 제공
- 제품 학습 : 사용자가 인지하고자 하는 사물 촬영 및 저장을 통해 인식 기능 제공
- 제품 식별 : 최대 150개까지 제품 바코드를 저장하여 인식기능 제공
- 화폐 식별 : 화폐 촬영을 통해 돈의 단위를 TTS 음성으로 정보 제공
