# Seed Memory

현재 폴더는 실제 RAG 저장소로 교체하기 전 검색 인터페이스와 에이전트 흐름을 검증하는 데이터다.

## Tier 기준

| Tier | 의미 | 주요 자료 | 현재 보존 개념 |
|---|---|---|---|
| STM | 최신 대화와 당일 업무 흐름 | 대화 요약, 통화 메모, action item | 약 1주 |
| MTM | 진행 중인 프로젝트 지식 | 회의록, 초안, 일정표, 검토 보고 | 약 1개월 이상 |
| LTM | 승인된 조직 기준 지식 | 최종 계획서, 규정, 작성 기준 | 장기 보존 |

모든 문서는 `memory_tier`, `source_type`, `project`, `title`, `date`,
`permission_scope`, `status`, `summary` 메타데이터를 갖는 것을 원칙으로 한다.

## 연결된 검증 시나리오

- `오늘 A 과제 회의에서 정한 다음 일정과 담당자는?`
  - STM 중심 prefetch와 추가 STM tool call 확인
- `A 과제의 최근 내부 목표일이 공식 계획과 충돌해?`
  - STM, MTM, LTM 혼합 prefetch와 LTM 추가 검색 확인
- `B 과제 시범 분석 결과와 공식 일정의 차이를 알려줘`
  - MTM 진행 자료와 LTM 승인 계획 비교 확인
- `조직 문서에서 확정 정보와 논의 중 정보를 어떻게 구분해야 해?`
  - LTM 중심 검색 확인

실제 RAG 전환 시에는 파일 하나를 문서 단위로 수집하고, 제목과 본문 구획을 기준으로
chunk를 만든 뒤 동일 메타데이터를 각 chunk에 복제하는 방식으로 이전한다.
