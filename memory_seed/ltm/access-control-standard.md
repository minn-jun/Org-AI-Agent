# 문서 접근 권한 기준

## 적용 원칙

- 공개 범위는 전사, 부서, 과제팀, 담당자 한정 네 단계다.
- 과제팀 이상 등급 문서의 외부 공유는 책임자 승인이 필요하다.
- 권한 등급은 문서 생성 시 지정하고 변경 이력을 남긴다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
