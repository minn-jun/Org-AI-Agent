# 감사 대응 절차

## 적용 원칙

- 원본과 사본을 구분해 제출한다.
- 제출 목록과 담당자를 기록으로 남긴다.
- 추가 요청은 과제책임자를 경유한다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
