# 데이터 취급 지침

## 적용 원칙

- 기관별 데이터는 공통 전처리 기준을 적용한 뒤 비교한다.
- 누락값 처리 방식은 분석 보고서에 명시한다.
- 분석 버전과 검토자를 함께 기록한다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
