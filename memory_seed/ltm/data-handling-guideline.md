# 프로젝트 데이터 처리 및 결과 검토 지침

## 필수 기록

- 데이터 수집 기준일과 제공 기관
- 공통 컬럼 정의와 전처리 규칙
- 누락값 및 이상치 처리 방식
- 분석 코드 또는 산출물 버전
- 작성자와 검토자

## 결과 공유 조건

- 기관별 처리 방식이 다르면 공통 기준으로 다시 산출한다.
- 검토 전 결과는 `in_review` 상태로 표시한다.
- 외부 공유 전 프로젝트 책임자의 승인을 받는다.
