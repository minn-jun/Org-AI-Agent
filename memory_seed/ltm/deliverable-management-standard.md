# 산출물 관리 기준

## 적용 원칙

- 산출물에는 유형, 버전, 담당자, 승인 상태를 표기한다.
- 최종본은 별도 목록으로 관리한다.
- 폐기된 버전은 목록에서 제외하되 이력은 남긴다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
