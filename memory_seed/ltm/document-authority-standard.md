# 조직 문서 상태 및 우선순위 기준

## 상태 우선순위

1. 승인된 최종 문서
2. 검토 완료 문서
3. 검토 중인 진행 문서
4. 초안
5. 대화 및 개인 메모

## 적용 원칙

- 최신 대화는 현재 진행 상황을 설명할 수 있지만 승인 문서의 공식 기준을 자동으로 대체하지 않는다.
- 일정이 다르면 내부 목표일과 공식 마일스톤을 구분해 표시한다.
- 개정 문서는 이전 문서의 식별자와 변경 사유를 남긴다.
- 답변에는 사용한 문서의 상태와 날짜를 함께 제시한다.
