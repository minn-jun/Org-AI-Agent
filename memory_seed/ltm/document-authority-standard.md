# 문서 권위 판단 기준

## 적용 원칙

- 권위 순서는 승인 최종본, 검토 완료본, 진행 중 초안, 대화 메모 순이다.
- 같은 등급이면 최신 개정본을 우선한다.
- 충돌이 확인되면 상위 문서 기준을 따르고 하위 문서에 변경 사유를 남긴다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
