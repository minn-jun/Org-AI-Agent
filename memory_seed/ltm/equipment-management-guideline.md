# 연구장비 관리 지침

## 적용 원칙

- 장비는 대장에 등록한다.
- 사용 전후 점검 기록을 남긴다.
- 고장 발생 시 즉시 관리자에게 통보한다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
