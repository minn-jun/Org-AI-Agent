# 지식 승격 정책

## 적용 원칙

- 승격 판단 요소는 확정성, 재사용성, 대표성, 최신성, 권한성, 출처성이다.
- 승격은 담당자 승인 후에만 이루어진다.
- 승격된 문서는 원본 MTM 문서에 승격 사실을 표시한다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
