# 회의 운영 지침

## 적용 원칙

- 안건과 목표를 회의 전에 공유한다.
- 종료 시 결정사항과 action item을 정리한다.
- action item에는 담당자와 기한을 반드시 적는다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
