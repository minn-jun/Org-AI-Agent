# 보고서 작성 지침

## 적용 원칙

- 결정사항과 논의 중 사항을 반드시 구분해 적는다.
- 미해결 쟁점에는 담당자와 기한을 함께 적는다.
- 인용한 문서는 출처 항목에 모아 적는다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
