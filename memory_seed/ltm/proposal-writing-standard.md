# 제안서 작성 기준

## 적용 원칙

- 필수 항목은 추진 배경, 목표, 수행 체계, 일정, 예산 산정 근거, 기대효과다.
- 일정과 예산에는 근거 문서 이름을 함께 적는다.
- 초안은 내부 검토를 거친 뒤 수정본으로 승격한다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
