# 품질 검토 지침

## 적용 원칙

- 작성자 외 1인 이상이 검토한다.
- 검토 의견과 반영 여부를 기록한다.
- 미반영 의견은 사유를 남긴다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
