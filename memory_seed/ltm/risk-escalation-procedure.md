# 이슈 보고 절차

## 적용 원칙

- 지연이나 초과가 예상되면 즉시 과제책임자에게 보고한다.
- 주간 보고에 리스크 항목으로 등재한다.
- 해소 시 종결 사유를 함께 기록한다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
