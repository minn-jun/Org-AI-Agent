# 일정 변경 절차

## 적용 원칙

- 공식 마일스톤 변경은 책임자 승인을 받는다.
- 변경 사유, 영향 범위, 대안 일정을 함께 제출한다.
- 내부 목표일 조정은 팀 내 공유로 갈음하되 공식 일정과의 차이를 표시한다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
