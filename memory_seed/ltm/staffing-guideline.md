# 인력 투입 지침

## 적용 원칙

- 참여율은 월 단위로 관리한다.
- 동일 인력의 총 참여율은 100퍼센트를 넘을 수 없다.
- 변경 시 과제책임자 간 협의를 거친다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
