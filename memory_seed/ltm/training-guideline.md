# 연구원 교육 지침

## 적용 원칙

- 착수 후 2주 이내 보안 교육을 이수한다.
- 데이터 취급 교육을 함께 이수한다.
- 이수 여부는 과제책임자가 확인한다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
