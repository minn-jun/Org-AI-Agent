# 출장비 처리 지침

## 적용 원칙

- 출장은 사전 신청과 승인이 필요하다.
- 복귀 후 5일 이내 결과 보고와 증빙을 제출한다.
- 증빙이 없는 항목은 정산 대상에서 제외한다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
