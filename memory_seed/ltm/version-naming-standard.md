# 문서 버전 표기 기준

## 적용 원칙

- 버전은 초안, 검토본, 승인본 순으로 표기한다.
- 파일명에 날짜와 버전을 함께 적는다.
- 승인본 이후 변경은 새 버전으로 만든다.

## 예외 처리

- 예외가 필요하면 사유와 승인자를 문서에 남긴다.
