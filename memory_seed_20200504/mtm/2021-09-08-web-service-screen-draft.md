# 웹 서비스 화면 설계 초안

## 화면 구성

- 사용자 화면: 로그인 → 시각 유형 선택 → 훈련 세션 → 결과 확인
- 보조 서비스 화면: 실시간 영상 보정 상태, 센서 경고 표시

## 미정의

- 관리자 화면(사용자 관리, 훈련 이력 조회)
- 기관 계정과 개인 계정의 권한 구분

## 참고

- 화면 항목은 계획서의 서비스 기능 정의와 대조해야 한다.
