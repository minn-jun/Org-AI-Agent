# 협약 변경 필요 여부 검토

## 검토 배경

- 참여연구원 구성이 착수 시점 계획과 달라졌다.
- 세부 계획금액 조정이 필요하다.

## 변경 후보

- 참여연구원 명단
- 연차별 계획금액

## 확인 필요

- 통보성 변경인지 승인 대상 변경인지
- 변경 신청 시기와 필요 서류
- 협약서 원문의 변경 조항
