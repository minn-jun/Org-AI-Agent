# 웹 서비스 화면 설계 2차본

## 확정 사항

- 훈련 서비스 화면 12종
- 시각 보정 서비스 화면 5종
- 공통 로그인 및 계정 관리

## 연기

- 관리자 화면은 2차년도로 미룬다.

## 확인 필요

- 1차년도 개발 범위에서 관리자 화면을 빼는 것이
  공식 계획서의 연차별 개발 내용과 어긋나는지 확인해야 한다.
