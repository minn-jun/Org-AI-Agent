# HMD 결합형 기구 디자인 검토 (GLASS-20211026)

## 검토 대상

- 피씨티 제출 도면 세트 GLASS-20211026
- HMD 모듈, 영상처리 보드, 컨트롤러 보드 결합형 구성

## 검토 결과

- 전면 무게중심이 앞으로 쏠려 장시간 착용 시 코받침 압박이 크다.
- 배터리 위치를 후면으로 옮기면 무게 배분은 개선되나 케이블 경로가 길어진다.
- 영상처리 보드 발열이 관자놀이 접촉면에 그대로 전달된다.

## 요청 사항

- 무게중심 재배치안 2종을 12월 첫 주까지 제시할 것
- 발열 차폐 구조를 BOM에 반영할 것

## 남은 확인

- 1차년도 성능지표의 착용 중량 목표치는 공식 계획서 기준으로 확인이 필요하다.
