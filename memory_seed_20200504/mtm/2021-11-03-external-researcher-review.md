# 외부연구원 참여 검토

## 배경

- 서비스 서버 구축과 화면 개발 인력이 부족하다.
- 외부 업체 소속 개발자를 참여연구원으로 등록하는 방안을 검토했다.

## 검토 대상

- 협력 업체 소속 개발 인력 1명

## 준비 서류

- 근로계약서
- 참여율 산정 근거
- 소속 기관 동의

## 확인 필요

- 영리기관 소속 인력이 참여연구원으로 등록 가능한지
- 공통운영요령상 참여 제한 요건에 걸리는지
