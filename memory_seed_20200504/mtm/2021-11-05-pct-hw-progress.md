# ㈜피씨티 H/W 개발 진척 보고

## 완료

- Head Mounted Display 모듈 시제품 제작
- 영상처리 프로세서 보드 1차 제작
- 컨트롤러 보드 결합 시험

## 진행 중

- 증강현실 영상 출력 지연이 목표치를 넘는다. 펌웨어 측 버퍼 구조를 수정 중이다.
- 영상 보정 알고리즘은 터널시야 유형만 적용된 상태다.

## 미착수

- 시험성적서 발급을 위한 사전 시험
- 제품 인증 절차

## 비고

- 지연 수치의 1차년도 목표치는 공식 계획서의 기술개발 목표 성능지표 표를 따른다.
