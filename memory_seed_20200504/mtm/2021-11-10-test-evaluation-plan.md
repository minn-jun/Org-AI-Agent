# 시험평가 항목 정의

## 평가 항목

| 항목 | 측정 대상 | 측정 조건 |
|---|---|---|
| 증강현실 영상 출력 지연 | HMD 모듈 | 실내 조도 500lx, 30분 연속 |
| 착용 중량 | 결합형 본체 | 배터리 포함 |
| 센서 감지 거리 | 초음파·적외선 모듈 | 정면 기준 |
| 훈련 세션 기록 | 서비스 서버 | 100세션 연속 |

## 측정 주체

- H/W 항목은 피씨티, 서비스 항목은 가천대

## 확인 필요

- 각 항목의 목표치와 평가 방법은 계획서의 목표 성능지표 표를 따른다.
