# 시각 유형별 UI/UX 설계 초안

## 공통 원칙

- 조작 단계는 3단계를 넘지 않는다.
- 모든 상태 변화는 음성 안내를 함께 제공한다.

## 유형별

| 유형 | 화면 구성 | 주 조작 |
|---|---|---|
| 터널시야 | 주변부 축소 표시, 중심 유지 | 시야 확장 배율 조절 |
| 황반원공 | 중심 회피 배치 | 주시점 이동 |
| 색각이상 | 대비 강화 팔레트 | 팔레트 전환 |
| 원·근시 | 초점 거리 프리셋 | 프리셋 선택 |

## 남은 작업

- 색각이상 보정 계수는 임상 자문 없이 정한 값이라 검증이 필요하다.
- 실제 착용 시험은 피씨티 펌웨어 수정본 입고 후로 미뤘다.
