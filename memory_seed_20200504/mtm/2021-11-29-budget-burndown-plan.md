# 연말 예산 소진 계획

## 12월 집행 예정

- 디자인 컨설팅비 4,500,000원 (12-31까지 지급)
- 선행특허 조사 용역비
- 시제품 추가 제작비

## 세목별 전망

| 세목 | 전망 |
|---|---|
| 인건비 | 잔액 발생 |
| 연구활동비 | 부족 |
| 연구재료비 | 정상 |

## 대응 방향

- 세목 변경으로 연구활동비를 보강한다.
- 남는 인건비는 이월을 검토한다.

## 확인 필요

- 세목 변경 허용 범위와 이월 한도
