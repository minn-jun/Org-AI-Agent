# 외부연구원 참여 불가 결정과 대응

## 결과

- 검토했던 외부 업체 소속 인력의 참여연구원 등록이 불가로 정리됐다.
- 사유는 소속 형태와 참여율 요건 미충족이다.

## 영향

- 해당 인력분으로 잡아 둔 인건비가 집행되지 못한다.
- 서비스 서버 구축 일정이 다시 밀린다.

## 대응

- 대체 인력을 신규 채용으로 전환한다.
- 채용 공고와 절차가 2022년 1월로 넘어간다.
- 집행하지 못한 인건비는 이월을 신청한다.

## 확인 필요

- 참여연구원 변경이 협약 변경 대상인지
