# 특허 출원 명세서 초안

## 출원 대상

- 시각 이상 유형별 영상 보정 파라미터 분기 구조
- 훈련 이력에 따른 난이도 자동 조정 방식

## 선행특허 반영

- 태창특허법률사무소 조사에서 나온 회피 검토 2건을 청구항에서 우회했다.
- RFID 기반 구성과 다중 안테나 선택 전원 구조는 청구 범위에 넣지 않았다.

## 남은 작업

- 도면 작성
- 발명신고서 제출

## 확인 필요

- 지식재산권 관리 시행지침상 발명신고서 기재 항목
- 출원 비용 부담 주체
