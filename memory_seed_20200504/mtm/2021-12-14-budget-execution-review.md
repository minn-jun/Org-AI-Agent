# 2단계 1차년도 예산 집행 점검

## 기준

- 2단계 1차년도 정부출연금 443,750천원
- 민간부담금은 별도 관리

## 세목별 현황

| 세목 | 상태 | 비고 |
|---|---|---|
| 인건비 | 잔액 발생 예상 | 학생연구원 참여율 하향 |
| 연구활동비 | 부족 | 특허 용역비, 시제품 제작비 증가 |
| 연구재료비 | 정상 | |
| 간접비 | 정상 | 요율 고정 |

## 판단

- 세목 변경으로 연구활동비를 보강하고, 그래도 남는 금액은 이월을 신청한다.
- 변경 한도와 승인 절차는 사업비 관리 기준을 따라야 한다.
