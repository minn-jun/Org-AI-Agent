# 연구비 세목 변경 검토안

## 변경 방향

- 인건비 → 연구활동비

## 변경 사유

- 학생연구원 참여율 하향으로 인건비 집행 잔액 발생
- 선행특허 조사 용역비와 시제품 추가 제작비로 연구활동비 초과 지출

## 산출 근거

- 인건비 잔액은 월별 참여율 실적 기준으로 산출했다.
- 연구활동비 부족분은 12월 확정 지출 예정액 기준이다.

## 확인 필요

- 세목 간 변경 허용 범위
- 전문기관 사전 승인 대상인지 여부
- 연차보고서 4장 사업비 집행 실적과의 정합성
