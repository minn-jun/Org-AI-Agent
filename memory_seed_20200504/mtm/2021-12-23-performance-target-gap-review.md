# 1차년도 성능지표 달성도 점검

## 달성

- 시기능 훈련 유형 수 4종
- 훈련 서비스 세션 기록 기능
- 시각 보정 서비스 화면 구성

## 미달

| 항목 | 상태 | 원인 |
|---|---|---|
| 증강현실 영상 출력 지연 | 목표치 초과 | 펌웨어 버퍼 구조 |
| 착용 중량 | 목표치 초과 | 전면 무게중심 재설계 진행 중 |

## 대응

- 두 항목 모두 2차년도 1분기 내 개선 계획을 연차보고서에 명시한다.
- 목표치 원문은 공식 계획서의 기술개발 목표 성능지표 표를 인용한다.

## 주의

- 이 문서의 달성 판단은 내부 측정 기준이다. 공식 평가 기준과 다를 수 있다.
