# 2021-12-28 전문기관 문의 통화 메모

## 문의 내용

- 인건비에서 연구활동비로 세목 변경이 가능한지
- 연구비 이월 신청 시 필요한 서류

## 답변 요지

- 세목 변경은 변경 요청서 제출로 처리 가능하다.
- 이월은 사유서와 2차년도 사용 계획을 함께 제출해야 한다.
- 이월 한도와 허용 사유는 사업비 관리 기준을 따른다.

## 확인 필요

- 통화로 받은 내용이라 공식 기준 원문을 다시 확인해야 한다.
